# Les pages de mai (v0.5), archivées le 25.11.2026

Le site de mai (v0.5, 8 mai 2026) avait quatre pages intérieures : Imprimer (`build.astro`), Code (`code.astro`), Démos
(`demos.astro`) et Journal (`journal.astro`). Le 25.11.2026, quand Yoan a confié le site à Claude (« This website is yours… make it
great »), elles étaient figées :

- **Imprimer** décrivait le bras SO-ARM100 ; N0.1, le robot qu'on imprime, n'y était pas.
- **Démos** montrait les vidéos du bras, hébergées dans le dépôt `dyad`, qui est privé : elles ne s'affichaient pour personne.
- **Code** pointait vers `dyad` (privé, donc introuvable pour un visiteur) et vers des dépôts sans rapport avec Navitek ; « [ Dashboard
  live arrive ] » y attendait encore.
- **Journal** n'avait qu'une entrée, celle du 8 mai (elle est reprise telle quelle au bas du nouveau journal).

Elles sont gardées ici, hors de `src/`, donc plus construites : rien n'est supprimé (la règle du dépôt de travail). Les nouvelles pages :
`/build` (Imprimer N0.1), `/code` (le code et les données), `/films` (l'ancienne `/demos` y renvoie), `/journal` (les cahiers).
